# 实验与质量验证

## 目的

评测用于验证 RAG、上下文组装和作者约束是否真正改善续写，不替代作者对文学质量的最终判断。

## 题目分型

| 类型 | 验证重点 |
| --- | --- |
| RAG 敏感 | 能否找到、使用并转化与当前断点相关的证据。 |
| 约束敏感 | 能否遵守作者确认的场景边界和人物一致性。 |
| 开放创作 | 能否在不改变主线因果的前提下推进剧情、维持张力与人物主动性。 |

## 指标

- 基础质量：断点承接、事实遵循、人物一致、剧情连贯/推进、文本可读性。
- 题型专项质量：依据题目类型使用不同权重，避免用约束型标准压制开放创作。
- 风险：严重冲突、无依据断言、未来信息泄漏、人工复核率。
- 效率：成功率、失败率、耗时和实际 token 成本估算。

最终净质量 = 正向质量 - 风险扣分。多轮实验仅汇总成功且 Judge 输出有效的样本，并展示均值、标准差及相对基线差值。

## 稳定性机制

- 对网络异常和模型空响应使用有限次数重试。
- 对 JSON 输出进行提取、修复与 schema 校验；修复失败记录原因而非静默丢弃。
- 对接近长度上限且未在完整句收束的文本，标记为未完成生成并仅重试一次。
- 支持按整组或单项覆盖重跑，保证同一轮 A/B/C 的可比性。

## 已验证结论

在内部的 3 部作品、162 个可比样本实验中，增强上下文链路相较基础生成的综合质量提升为 7–17 分。公开版本不包含真实作品、原始样本或实验明细。
