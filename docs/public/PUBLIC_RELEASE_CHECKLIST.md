# 公开发布前检查清单

## 必须排除

- [ ] 真实小说原文、章节快照、解析输出、向量索引、生成正文与评测运行记录。
- [ ] `.env.local`、API Key、数据库备份、真实服务地址、浏览器用户数据和日志。
- [ ] 内部讨论、开发计划、个人路径、未授权图片、视频及第三方字体素材。
- [ ] 包含受版权保护作品名称、片段或测试细节的内部题库与文档。

## 必须保留

- [ ] `.env.example` 只包含变量名与 `change-me` 占位符。
- [ ] 自创或已获授权的 Demo 作品、人物、线索与截图。
- [ ] README、架构文档、启动说明、License 与数据边界说明。
- [ ] 发布前执行 `git status --ignored`，确认被忽略内容没有误加入暂存区。

## 发布流程

1. 新建公开 GitHub 仓库，不勾选自动生成 README。
2. 在本地确认 `git diff --cached` 只包含代码、公开文档和虚构 Demo 数据。
3. 执行 `npm test` 与 `npm run build`。
4. 推送前再次检查 GitHub 的文件列表，确认没有密钥、真实小说数据和本地数据库文件。
5. 在仓库 About 中填写：`RAG`、`LLM`、`AI Product`、`Next.js`、`PostgreSQL`、`pgvector`。
